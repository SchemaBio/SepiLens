# ACMG/AMP 2015 Sequence Variant Agent 规约

- **引擎标识**：`acmg_amp_2015`
- **目标**：梳理序列变异与疾病关联的可查证文献和结构化证据，提议候选证据项及支持依据。
- **约束与禁止事项**：
  1. 智能体仅能输出 `agent_proposal`，禁止直接判定或覆写 `rule_engine_result`。
  2. 检索未发现相关证据时，必须如实报告为缺乏证据，禁止将未检索到文献转化为良性证据。
  3. 必须保留变异–疾病–遗传模式（variant–disease–MOI）上下文，禁止对孤立变异字符串做固定断言。
