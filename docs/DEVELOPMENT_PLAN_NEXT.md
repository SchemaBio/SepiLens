# SepiLens 外部证据服务开发进度

版本 v3.1；2026-10-20。目标为 YiJian JSON 输入、SepiLens 规则与受控联网评估；只修改 SepiLens。

## 已实现的架构

- 医学数据库导入、SQLite 注释索引、本地数据查询、bundle 启动配置和 /v1 路由已移除。HPO 翻译全量资产从部署资源移除，只保留20条测试夹具。
- /v2/evaluations 接收版本化证据 JSON，支持四引擎。本地同步持久化后返回200，LLM异步返回202。保留 API Key 租户绑定，新增证据提交权限及来源版本／身份／许可／时效校验。
- 四引擎消费不可变输入，CNV Gain/Loss 保持独立规则和整数计分；表型按请求构造临时图及背景上下文，无医学数据库依赖。PVS1、PP4、完整覆盖不足时保留缺口。
- 多轮工具支持 Responses/Chat，预算、引用与事实约束、六类 change 裁决、遗漏保留和服务端重算。SVC 仅确认已有专家编码方法结果，不能由模型任意改写方法值；实验结果始终不能进入正式临床结果。
- 规则批准改为绑定输入契约、来源策略、实现和独立验证报告。新业务格式拒绝旧数据库，默认 sepilens-v2.db，不自动删除或迁移旧文件。
- 人工修订从已保存有效条款合并重算，新 revision 清除旧审核；快照、审计、加密、密钥轮换、删除和保留继续生效。

## 验收范围与剩余工作

以本轮实际测试及 docs/reports/v2 下的记录为准。旧 next/rc 报告属于历史，不证明当前版本通过验收。

部署方需与 YiJian 实际联调来源清单、剂量包及覆盖声明，补齐人群AC/AN、机制、转录本和家系材料；缺失时不自动补推。真实厂商联网验收需凭据，本轮不调用付费厂商。医学团队仍需独立黄金病例、参数审阅及签名批准。

SVC 覆盖现有锁定草案 scorer 的适用范围，上游未完成的 motif/noncoding 原始决策等缺口仍存在；四套双模式入口不代表所有条款都可由位点自动获得。所有医学引擎默认禁用，SVC临床禁用，AI默认disabled。工程交付不代表医学批准。

对接字段、示例及运行方式见 [YiJian契约](YIJIAN_INTEGRATION.md)、[API](API.md)、[部署](DEPLOYMENT.md)。
