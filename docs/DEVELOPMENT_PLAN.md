# 首版交付进度

本文件取代原 alpha 里无验证依据的完成声明。用户批准计划的工程实现和临床启用分开验收，当前候选不发布医学批准。

| 阶段 | 已落实 | 未通过的退出条件 |
|---|---|---|
| A | 入口、启动关闭、配置、CI、默认禁用及内容签名门禁 | 发布包最终检查以 VALIDATION 报告为准 |
| B | 加密、迁移、队列、租约、幂等、取消、事务交付、SSE | 现场断电和部署硬件长期运行尚未验收 |
| C | 两协议、探测、锁定导入、参考序列、HPO 候选跨度与极性 | 真实模型联调、完整官方数据许可与中文资源许可 |
| D | 官方接口、许可全文、空结果补查、一层引用追踪、来源分层、追加快照、审核版本、审计、删除 | 真实检索对照验收 |
| E | ACMG 28 条件、独立 CNV rubric、适用性/整数/上限、导出与比较工具 | 每条独立六类黄金案例、官方对照清零、专家签名；复杂基因内事件临床对照 |
| F | 二进制、双架构镜像构建流程、部署/运维/API 文档和测试工具 | 最终发布验证以报告为准；无医疗启用批准 |

未通过项目不标为完成。规则包矩阵列出每个条款缺少的案例类别。SVC v4 临床引擎禁用，锁定草案实验评分纳入交付；Anthropic、集群、Web UI 和通用搜索不在本轮范围。
