1. Parquet 无 schema 元数据，缓存无 JSON 清单，未记录 assembly 或 ClinVar 版本；本次检查的归档目录中也未找到可补充这两项的 catalogue/manifest。尚需经授权查询任务参考基因组、流程/注释版本和结果批次关联，不能从现行默认配置推断历史任务版本。
2. 变异对象核对后，ClinVar 仍只是聚合分类参照，不能生成条款级“已专业复核”标签，也不能推导 SVC 正式疾病关联或方法输入。[NCBI 分类说明](https://www.ncbi.nlm.nih.gov/clinvar/docs/clinsig/)

4. 原有模型输入可能包含 ClinVar 结论。包含答案的 annotation-assisted 一致性必须与屏蔽该参照的实验区分，不能作为独立准确性提升依据。
5. 准确性比较需要使用本地新版本的隔离执行器；当前部署的旧版本不能代表新证据链。生产正常用户入口不应用于评测，避免用户积分或真实任务变更。
