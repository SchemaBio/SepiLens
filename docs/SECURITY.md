# 安全与隐私

认证把 Token 固定绑定 tenant、actor 和角色。查询均按租户过滤，profile 管理、能力测试和租户删除需要 admin；审核需要 reviewer/admin，提交者不能通过请求中的 reviewer_id 冒充审核者。应在服务前配置 TLS，限制入站网络和认证 Token 权限。

敏感负载使用 AES-256-GCM，加密密钥由部署方提供，AAD 绑定租户、任务/快照/profile 标识及负载用途。患者 HPO 原文只在本次调用内存中处理，不持久化；结构化输入、模型提议、结果、证据、profile 密钥和审核加密保存。profile API 永不读回密钥。日志仅输出固定路由、状态、耗时等运行元数据，不输出患者原文、提示词、密钥及完整外部错误。

外部 transport 默认仅接受公网 HTTPS，连接时解析并验证全部 DNS 地址，将连接固定到已验证 IP，禁用重定向和代理继承。私网、回环、特殊用途地址和混合 DNS 答案拒绝；显式 `SEPILENS_ALLOW_PRIVATE_ENDPOINTS=true` 才允许内网模型。该选项属于部署信任边界，开启后请通过网络 ACL 限定可达端点。

模型输出严格校验结构、候选 ID、来源、事实字段及大小。外部文本经过清理；文本中的命令、关键词或置信度不触发正式计分。来源必须分别通过标识、存在、对象匹配和材料核验；没有完整核验的证据只能作为提议。

新证据快照只能追加，读取重算 SHA-256；加密认证或散列异常使读取失败。审核修正保存旧结果和旧快照，并以新 revision 返回。散列不是外部时间戳服务：数据库删除/元数据破坏需要部署方备份与访问控制防护，不能宣称抵抗已掌握数据库和主密钥的管理员。

默认保留 90 天，删除按租户隔离。SQLite 删除不保证介质物理擦除，数据库页、WAL 和旧备份应配合全盘加密及介质销毁策略。实际厂商是否保留请求由其合同和配置决定；Responses 请求使用 store=false，不宣称代表所有厂商的零保留。
