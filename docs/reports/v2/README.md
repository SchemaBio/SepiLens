2026-10-20。本目录记录本轮实际运行结果；历史 next/rc 报告不用于替代本次检查。

- Windows：全量 Go 测试、vet、构建通过；无医学数据库 smoke 39项通过。
- WSL Ubuntu：全量 race、vet、构建通过；无医学数据库 smoke 39项通过。
- OpenAPI 重建一致性检查通过。
- 四引擎 × 两协议 × 成功／失败共16个 mock 场景通过；成功流程使用只读工具后继续模型调用。SVC 另覆盖非空 POP 确认与引用别名还原。

详见 verification.json、smoke-windows.json、smoke-linux.json。smoke 吞吐与P95仅为16次、4并发的合成本地请求，不反映真实病例、模型延迟或临床准确率。模型测试需要允许本机回环连接；Windows 沙箱限制下的网络失败经沙箱外同一mock复验通过，默认SSRF防护未放宽。

响应示例见 ../../examples/v2：来自实际服务的合成 simulation／experimental 运行，不能作为独立临床黄金期望。
